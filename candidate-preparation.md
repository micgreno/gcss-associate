# Practical assessment: preparation

The interview will include a 60-minute, in-person practical assessment. You do not need to review an application or repository in advance. At the beginning of the assessment, you will receive the detailed instructions, including the GitHub repository that contains the app and steps to install and run it locally.

## Please bring

- A personal laptop with Python 3.10 or later installed
- Visual Studio Code (VS Code)
- A current web browser
- Your laptop's power adapter
- Optional: access to any free-tier AI/LLM assistant you would like to use during the assessment. No paid plan is needed.

Before the interview, please check that VS Code opens and Python is available from its built-in terminal:

- macOS: open **Terminal → New Terminal** in VS Code and run `python3 --version`; confirm it reports 3.10 or later
- Windows: open **Terminal → New Terminal** in VS Code and run `py -3 --version`; confirm it reports 3.10 or later

There is no need to download or inspect the repository before the interview. If Python or VS Code setup is giving you trouble, let us know ahead of time so we can plan to help.
